Téma: Typy API
Otázka: GraphQL server obmedzuje maximálnu hĺbku query. Prečo samotný limit hĺbky nestačí na ochranu pred drahými query?
Odpovede:
+ limit hĺbky neobmedzí šírku query — počet položiek na každej úrovni môže stále rásť (napr. 10 × 10 × 10)
- limit hĺbky sa uplatňuje iba na mutácie, nie na query
- klient môže limit hĺbky obísť, ak pošle query cez HTTP GET namiesto POST
- limit hĺbky zakáže aj jednoduché query, a preto sa v praxi vypína
